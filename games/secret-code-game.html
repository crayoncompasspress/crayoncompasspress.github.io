Robot secret code: crack the message

Each number stands for a letter. Use the key to decode the robot's message, then type it in to check. Ages 7 to 12. Free, no ads, no sign-up.

The code

The key

How to play

  1. Pick a level. Trainee uses A=1, B=2 and so on.
  2. Find each number in the key and write down its letter. A slash shows a new word.
  3. Type the message and tap Check my answer.
  4. Detective and Master levels shift the key, just like a real cipher.

What it practices

  • Careful, step-by-step thinking
  • Working with a key or table
  • Patterns: how a shift cipher works

For grown-ups

Secret codes are a sneaky way to practice careful reading and checking. Kids who like this will enjoy making their own key and sending a coded note to a friend. At the Master level, the key changes every time, so they have to read the table instead of remembering it.

More codes, logic grids and a whole mystery are in Robot Brain Puzzles. Try the free two-player maze race too.

Questions

What age is it for?

Ages 7 to 12. Trainee level suits 7- and 8-year-olds; Master is tricky even for adults.

Do I need to type spaces?

No. Spaces and punctuation are ignored when you check.

Is this game free?

Yes. No ads, no sign-up and nothing to download.
